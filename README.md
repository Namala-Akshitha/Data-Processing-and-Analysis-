# Data Science Internship – February 2026
## Task 3: Python Programming Assignment – Data Processing and Analysis

### Overview
This repository contains my solutions for Task 3 of the Data Science Internship – February 2026. The assignment focuses on Python-based data processing, validation, frequency analysis, and basic statistical calculations.

### Problems Solved

1. **Employee Performance Bonus Eligibility** – Identifies the highest performance score and lists all employees tied for the top score.
2. **Search Query Keyword Analysis** – Normalizes search text, handles punctuation, counts keyword frequencies, and displays repeated keywords.
3. **Sensor Data Validation** – Identifies valid even-numbered sensor readings and stores their hour indices and values as tuples.
4. **Email Domain Usage Analysis** – Counts email domains and calculates their percentage of total usage.
5. **Sales Spike Detection** – Calculates average daily sales and identifies sales exceeding the specified threshold.
6. **Duplicate User ID Detection** – Identifies repeated user IDs and counts their occurrences.

### Technologies Used

- Jupyter Notebook
- Python data structures: dictionaries, lists, sets, and tuples
- String processing and basic statistical calculations
